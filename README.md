# Tithi Calendar

React frontend plus a small Node server for the locations API.

## Scripts

- `npm install`
- `npm run dev:server`
- `npm run dev:client`
- `npm run build`
- `npm run start`

## Structure

- `src/` React UI
- `server/` Node API and static build server
- `js/` shared tithi, date, location, and period-tracking logic
- `src/assets/` theme background images
